# Papi Pollo - Proyecto Backend Django

Proyecto desarrollado para la asignatura **Programación Back End - INACAP**.

## Versión 1 - Evaluación 1

Esta corresponde a la primera versión funcional del proyecto Papi Pollo.

El proyecto está desarrollado con Django y contiene dos aplicaciones:

- **Menu:** muestra los productos disponibles de Papi Pollo.
- **Sucursales:** muestra información de los locales y sucursales.

La información utilizada en esta primera versión se obtiene desde archivos JSON.

## Próxima etapa - Evaluación 2

A partir de esta primera versión se continuará desarrollando el proyecto incorporando los nuevos requerimientos correspondientes a la Evaluación 2.
